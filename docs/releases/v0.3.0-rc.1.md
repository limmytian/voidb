# VoidB v0.3.0-rc.1 Release Notes

> **Release Version**: `v0.3.0-rc.1`

> **Git Tag**: [`v0.3.0-rc.1`](https://github.com/limmytian/voidb/releases/tag/v0.3.0-rc.1)

> **License**: Apache 2.0  

VoidB v0.3.0-rc.1 是 VoidB 迈向轻量级、模块化生产数据库管理工具的关键里程碑版本。本版本彻底完成了从“庞大单体”向“精简核心 + 独立外置生态”的架构蜕变，聚焦核心 RDBMS 体验，并引入了全新的进程插件规范与包管理系统。

---

## 🌟 核心更新亮点 (Key Highlights)

### 1. 核心 RDBMS 聚焦与底座加固 (Core RDBMS Hardening)
- **主流关系型数据库精细化适配**：对 MySQL、PostgreSQL、SQLite、DuckDB 进行了深度的连接池约束、生命周期治理与连接 TTL 超时保护。
- **内存与性能优化**：TUI 核心底座精简，消除不必要的内置重型驱动依赖，构建产物精简，终端启动实现亚秒级响应。

### 2. 6 批长尾协议全面独立解耦 (Decoupled Protocols)
通过六批稳健的架构演进，将长尾协议从主仓库完全解耦为独立生态模块：
- **Batch 1 & 2**：网络管理协议与专用协议清理；
- **Batch 3**：Email / SMTP / IMAP 邮件管理协议外置；
- **Batch 4**：S3 / 对象存储协议外置（基于独立 SDK 扩展）；
- **Batch 5**：Docker & Kubernetes 云原生基础设施协议外置；
- **Batch 6**：Elasticsearch 检索与 MongoDB 文档数据库协议外置。

主仓库现在仅保留核心关系型数据库支持与高性能路由引擎，其他协议以独立插件形态运作。

### 3. 插件生态体系与工具链落地 (Plugin Ecosystem Tooling)
- **进程插件 SDK**：推出 `voidb-process-plugin-sdk`，支持跨语言/独立进程插件接入标准 JSON-RPC 协议与生命周期治理。
- **模板脚手架**：内置 `cargo-generate` 插件开发模板，开发者可一键生成标准插件工程。
- **离线包管理器**：`voidb-cli` 新增完整的插件包生命周期管理命令：
  - `voidb-cli plugin package`：打包输出规范的 `.tar.gz` 插件离线分发包及元数据。
  - `voidb-cli plugin install`：支持从本地包或 URL 快速安装并验证插件。
  - `voidb-cli plugin update`：支持一键检查版本并执行就地无缝升级。
- **第三方规范指南**：发布 [`docs/third-party-plugin-guide.md`](../third-party-plugin-guide.md)，明确能力声明、安全沙箱与官方认证等级标准。

### 4. 端到端加密配置同步 (E2E Encrypted Sync)
- **独立同步服务**：提供轻量级 `voidb-sync-server`，完全独立部署。
- **端到端加密安全**：客户端本地使用 AES-256-GCM 进行敏感凭据和连接配置加解密，服务端零知识（Zero-Knowledge）存储，确保团队与个人多端配置漫游的安全性。

## 🚀 快速上手 (Quick Start)

### 1. 运行终端管理器 (TUI)
```bash
./voidb
```

### 2. 使用 CLI 与插件管理
```bash
# 查看所有命令
./voidb-cli --help

# 打包或安装插件
./voidb-cli plugin install ./my-plugin-0.1.0-darwin-arm64.tar.gz
```

### 3. 运行配置同步服务器
```bash
./voidb-sync-server --host 0.0.0.0 --port 8080
```
