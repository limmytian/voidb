---

## 🌟 核心特性与架构升级 (Major Features)

### 1. 核心 RDBMS 聚焦与性能极致优化 (Core RDBMS Focus)
- **主流关系型数据库原生支持**：深度优化 MySQL, PostgreSQL, SQLite 与 DuckDB 的查询执行引擎、事务回滚与长连接池管理。
- **纯路由与轻量启动**：核心底座全面精简，去除臃肿的长尾依赖，交互 TUI 实现亚秒级秒开响应。

### 2. 八大独立插件外置与生态化 (8 Standalone Process Plugins)
全面完成了长尾与非关系型协议的独立建仓与外置演进，所有插件均通过 `voidb-process-plugin-sdk` 标准协议通信：
1. **`voidb-plugin-s3`**：AWS S3 与兼容对象存储（MinIO, Cloudflare R2, Ceph）
2. **`voidb-plugin-email`**：SMTP / IMAP 邮件服务器管理与内容收发
3. **`voidb-plugin-docker`**：容器、镜像、网络与卷管理，支持容器终端交互
4. **`voidb-plugin-kubernetes`**：Pod, Deployment, Service 等 K8s 资源实时巡检与状态监控
5. **`voidb-plugin-elasticsearch`**：ES 集群健康监控、索引映射管理与 REST 查询执行
6. **`voidb-plugin-mongodb`**：集合文档查询、CRUD 交互与数据库统计
7. **`voidb-plugin-jenkins`**：流水线作业状态触发、日志追踪与构建历史视图
8. **`voidb-plugin-webdav`**：WebDAV 文件存储共享与目录树检索

### 3. 官方 Registry 索引与自动化构建机制 (Plugin Registry & Indexer)
- **元数据规范设计**：发布 Draft 2020-12 标准的 `plugin-registry.schema.json` 元数据规范。
- **自动化索引生成**：提供 `voidb plugin registry-index` 自动化工具，支持批量扫描并自动生成 `registry/index.json` 官方分发清单。

### 4. 基于 Ed25519 的离线包签名与安全验签门禁 (Cryptographic Package Signing)
- **高强度非对称签名**：使用 Ed25519 算法对 `.tar`, `.tar.gz`, `.tar.zst` 插件包实施防篡改数字签名，生成独立 `.sig` 签名文件。
- **安全安装门禁**：`voidb plugin install` 与 `voidb plugin update` 支持 `--verify-key <PUBKEY>` 与 `--require-signature`，保障插件生态的供应链安全。

### 5. 跨平台多架构与端到端兼容性套件 (Cross-Platform Matrix)
- 覆盖 Linux (`ubuntu-latest`), macOS (`darwin-arm64`, `darwin-x64`) 与 Windows (`windows-latest`) 的自动化构建与兼容性门禁。
- 自动化端到端测试套件（`test-plugin-cross-platform.sh`）对全部 8 个独立插件的打包、签名、离线验签与安装完成 100% 实机验证。

### 6. 端到端加密配置漫游 (E2E Encrypted Sync)
- 提供独立轻量级同步服务 `voidb-sync-server`。
- 客户端使用 AES-256-GCM 本地加密敏感凭据，服务端零知识存储，确保个人与团队多端配置漫游的安全性。

## 🚀 快速上手与安装 (Quick Start)

### 1. 解压与运行
```bash
tar -xzf voidb-0.3.0-darwin-arm64.tar.gz
cd voidb-0.3.0-darwin-arm64

# 启动交互式 TUI
./voidb-default/voidb

# 使用命令行插件管理器
./cli/voidb-cli --version
```

### 2. 离线安装与验签独立插件
```bash
# 安装带 Ed25519 签名校验的插件包
voidb-cli plugin install voidb-plugin-s3-0.3.0.tar.zst \
  --verify-key "<OFFICIAL_PUBLIC_KEY>" \
  --require-signature
```
